# Exercícios HTML Semântico

Projeto desenvolvido para praticar HTML5 utilizando tags semânticas.

## Exercícios realizados:

- Exercício 1 - Estrutura semântica com header, nav, main, section, article, aside e footer.
- Exercício 2 - Conversão de layout com div para elementos semânticos.
- Exercício 3 - Uso de figure e figcaption.
- Exercício 4 - Criação de artigo usando article e section.
- Exercício 5 - Menu de navegação com nav e lista ul.

Tecnologias:
- HTML5
- CSS3
- Git/GitHub
